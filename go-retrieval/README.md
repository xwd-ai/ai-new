# 检索服务（Go）

把 Python 后端里的「关键词 + 向量双路召回 → RRF 融合」独立成一个 Go 进程。

## 为什么用 Go

- **双路召回天然可并行**：关键词检索与向量检索互不依赖，用 goroutine 并行后合并，
  不必像同步实现那样串行等待两段计算；
- **`context` 贯穿**：请求超时或客户端断开时，能取消仍在计算的下游任务；
- **单二进制部署**：无运行时依赖，镜像小、启动快。

## 运行

```bash
go run .                                  # 默认 127.0.0.1:8081
ADDR=127.0.0.1:9000 go run .              # 指定监听地址
```

