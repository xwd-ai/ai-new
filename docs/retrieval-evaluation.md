# 离线检索评测

工具入口为 `backend.evaluation.retrieval`，默认数据是 [retrieval_sample.json](../backend/evaluation/retrieval_sample.json)。五篇人工构造资料、六道题中有五道可回答、一道人为无答案题。相关性等级和方面标签由人工给定；向量排名、重排分数为独立提供的合成回放输入，算法不会从相关性标注生成排名。这是小型机制示例，不是生产质量基准。

在仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe -m backend.evaluation.retrieval --top-k 2
# 可保存到仓库外已存在的目录；不传 --output 时 JSON 输出到标准输出
.\.venv\Scripts\python.exe -m backend.evaluation.retrieval --top-k 2 --output E:\ai-new\partner-b-temp\retrieval-evaluation.json
```

`--dataset` 可指定同结构 JSON；`--top-k` 接受 1～20。输出目录需已存在，指定的文件会被覆盖；输入/写入错误返回退出码 2。无需联网、模型密钥或额外依赖。工具不导入应用入口，不查询数据库，也不加载环境变量和管理页设置。BM25 使用知识库服务的分词、评分与归一化函数；RRF、复合重排与 MMR 使用当前服务实现。预取、RRF 和 MMR 固定为代码默认值，重排使用服务默认复合分、候选上限和显式阈值 0。运行结果包含数据指纹、参数、变体定义、逐题排名、指标和相对 full 的差值；正差值不一定更好，例如误召回率越低越好。

## 消融定义

| 变体 | 行为 |
|---|---|
| keyword | BM25 排序直接截断 |
| full | 回放向量路 + BM25，经 RRF、回放重排（含服务复合分）、MMR |
| without_rrf | 固定 full 进入重排前的候选集合；移除 RRF 排序与召回分影响，按向量优先的稳定顺序去重、召回分统一为 1，再重排与 MMR |
| without_rerank | RRF 后直接 MMR |
| without_mmr | RRF 与重排后直接截断 |

`without_rrf` 只比较固定候选集上的排序/得分影响，不测 RRF 截断导致的候选覆盖变化。无向量排名时沿用关键词候选。回放向量分按名次倒数构造，仅为占位字段，RRF 实际只使用排名；它不是 embedding 相似度。重排按资料 passage 查预置分数，因此完全相同的 passage 不允许重复，避免分数映射歧义。

## 指标与输入约束

- Precision@k 分母固定为 k，即使不足 k 条；MRR@k 为第一份相关资料的名次倒数。
- Recall@k 以所有正等级资料为分母；nDCG@k 的增益为 `2^grade - 1`，理想排序来自全部标注的前 k 项。
- 方面召回率为命中相关资料所覆盖的不同方面数 / 全部相关方面数，用于区分重复资料与互补资料。
- 无答案题的 Recall、nDCG、方面召回率记为 null，不纳入这三项宏平均；其 Precision、MRR 为 0，仍纳入这两项宏平均。误召回率仅在无答案题上平均：返回任意资料计 1，否则计 0。

输入必须标记 `data_mode=synthetic_replay`。文档和题目 ID 需唯一；向量列表不得重复或引用未知资料；相关性为 0～3 的整数，正等级资料必须各有一个非空方面标签；每题重排分必须覆盖整个语料，且为 0～1 有限数值。数字字符串、未知字段、非法标注和非有限分数均拒绝。数据指纹是校验后 JSON（排序字段、UTF-8）的 SHA-256，不是原文件字节哈希。

## 示例结果（k=2）

数据指纹：`f00f1cf394c94991b882367285b07aede53aa2abdce3c8ce81750f9cf903cb09`。

| 变体 | Precision | Recall | MRR | nDCG | 方面召回率 | 无答案误召回率 |
|---|---:|---:|---:|---:|---:|---:|
| keyword | 0.5000 | 0.6667 | 0.6667 | 0.8000 | 0.7000 | 0.0000 |
| full | 0.5833 | 0.8667 | 0.8333 | 1.0000 | 1.0000 | 1.0000 |
| without_rrf | 0.5833 | 0.8667 | 0.8333 | 1.0000 | 1.0000 | 1.0000 |
| without_rerank | 0.5833 | 0.8667 | 0.8333 | 0.9420 | 1.0000 | 1.0000 |
| without_mmr | 0.5833 | 0.8667 | 0.8333 | 1.0000 | 0.9000 | 1.0000 |

该样例中取消 RRF 排序没有降低指标，不能据此宣称 RRF 有收益；重排改变部分顺序，MMR 将 export 题的重复格式资料换成权限资料，方面覆盖改善但 nDCG 不变。完整链路在唯一无答案题上误召回，提示仅比较可回答题会掩盖风险。样本很小、排名与分数均为合成回放，以上差异不能推广到业务语料或真实模型，也没有统计显著性含义。

替换为经审核的业务问题与独立标注，接入真实模型采集回放，再比较指标，才可用于调参决策。当前 HTTP 对话仍是关键词检索；运行此工具不会启用线上混合检索或修改部署配置。
